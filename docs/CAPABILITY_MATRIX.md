# Argo 기능 점검 행렬

왼쪽이 **구현할 최상위 기능**, 오른쪽이 **그 기능이 됐다고 말하려면 통과해야 할 항목**입니다.
각 항목은 앱 안의 진단 화면에서 버튼 한 번으로 돌아가고, 결과가 로그로 남습니다.

기호: `자동` = 코드가 스스로 판정 / `눈` = 화면을 보고 사람이 판정

---

## A. 워드 문서 읽기 (.docx / .doc)  ← 5단계 착수 대상

| # | 점검 항목 | 판정 | 통과 기준 |
|---|---|---|---|
| A1 | 컨테이너가 풀리는가 | 자동 | unzip 성공, `word/document.xml` 존재 |
| A2 | 글자가 나오는가 | 자동 | 추출 글자 수 > 0 |
| A3 | **문단이 쪼개지지 않았는가** | 자동 | 문단당 평균 글자 수 ≥ 12 — 1~3이면 분할 버그 |
| A4 | 표가 본문에 섞이지 않았는가 | 자동 | `<w:tbl>` 안 글자가 본문 문단에 안 들어감 |
| A5 | 비ASCII가 깨지지 않았는가 | 자동 | 한글·독일어 문자 비율이 원본 XML과 ±5% 이내 |
| A6 | 줄바꿈·탭이 보존되는가 | 자동 | `<w:br>` `<w:tab>` 이 공백으로 치환됨 |
| A7 | PDF로 변환되는가 | 자동 | 변환 성공, 쪽수 ≥ 1 |
| A8 | 변환본이 문서로 읽히는가 | 눈 | 여백·줄간격·쪽번호가 있는 문서 형태 |
| A9 | 기존 PDF 뷰어로 열리는가 | 눈 | 두 쪽 보기·쪽넘김·야간 모드 동작 |
| A10 | 닫으면 임시본이 지워지는가 | 자동 | 임시 폴더가 사라짐 |
| A11 | 큰 문서가 버티는가 | 자동 | 300쪽 분량 변환 시간 측정, 30초 이내 |
| A12 | `.doc`(구형)도 되는가 | 눈 | 글자가 어느 정도 나오고 크래시 없음 |

## B. 표 문서 읽기 (.xlsx / .xls)

| # | 점검 항목 | 판정 | 통과 기준 |
|---|---|---|---|
| B1 | 시트 개수가 맞는가 | 자동 | 탭 수 == `xl/workbook.xml` 의 시트 수 |
| B2 | **시트 이름이 진짜 이름인가** | 자동 | `Sheet 1` 이 아니라 원본 이름 |
| B3 | **시트 순서가 맞는가** | 자동 | 10개 넘는 파일로 sheet10이 sheet2 앞에 오지 않음 |
| B4 | 빈 칸이 자리를 지키는가 | 자동 | 셀 `r="C5"` 좌표 반영, 열 밀림 없음 |
| B5 | 숫자·날짜가 읽히는가 | 자동 | 날짜가 `45678` 같은 일련번호로 안 나옴 |
| B6 | 병합 셀이 깨지지 않는가 | 눈 | 내용 중복·누락 없음 |
| B7 | 표로 보이는가 | 눈 | 열이 세로로 맞음 |
| B8 | 큰 시트가 버티는가 | 자동 | 1만 행 처리 시간 측정 |

## C. 발표자료 읽기 (.pptx / .ppt)

| # | 점검 항목 | 판정 | 통과 기준 |
|---|---|---|---|
| C1 | 슬라이드 총수가 맞는가 | 자동 | 탭 수 == `ppt/slides/*.xml` 파일 수 |
| C2 | **빈 슬라이드가 사라지지 않는가** | 자동 | 글자 없는 장도 자리를 지킴 |
| C3 | **번호가 원본과 같은가** | 자동 | `slide9.xml` → "Slide 9" |
| C4 | 쪽번호 필드가 본문에 안 섞이는가 | 자동 | `<a:fld type="slidenum">` 제외 |
| C5 | 제목과 본문이 구분되는가 | 눈 | 제목이 크게 또는 머리글로 |
| C6 | 표가 섞이지 않는가 | 자동 | `<a:tbl>` 분리 |
| C7 | 발표자 노트가 보이는가 | 눈 | `ppt/notesSlides` 별도 표시 |

## 진행 순서

한 번에 하나씩만 합니다. **A가 끝나야 B로 갑니다.**

1. 진단 화면 골격 + A (워드) ← 지금
2. C (발표자료) — A의 변환기를 재사용
3. B (표)
4. D (한글)
5. E (PDF 뷰어 손질)
6. F·G (이미 코드는 있음, 확인만)
7. H (WebDAV)
8. I (두 칸 탐색기) — 파일 목록 뷰를 떼어내는 수술이 선행
