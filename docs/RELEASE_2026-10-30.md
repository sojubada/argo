## 2. 되돌리는 방법 (가벼운 것부터)

### 2-1. 다시 짓기만으로 끄기 (코드 그대로)
`rust/argoconv/Cargo.toml`의 `[features] default`에서 빼고 CI를 다시 돌린다.

| 증상 | 뺄 것 | 결과 |
|------|------|------|
| 한글 문서가 깨지거나 열리다 멈춤 | `"rhwp"` | 예전 hwpers 엔진만 쓴다 (D 전체 비활성) |
| 발표 문서(pptx/ppt)가 이상함 | `"slides"` | pptx는 예전 minipdf 변환기로. **.ppt 는 다시 못 연다** |

둘 다 빼려면 `default = []`.

### 2-2. 기능 하나만 되돌리기 (git)
뒤에 커밋이 쌓여 있으므로 `git revert`를 쓴다(기록이 남고 다른 기능은 그대로).

```
git revert --no-edit 0d2c734            # H 묶음 수정만
git revert --no-edit c05dc7f            # G: .ppt·그림자 (F보다 먼저)
git revert --no-edit d214999            # F: 새 렌더러 (G, H 먼저 되돌린 뒤)
git revert --no-edit b3566b8            # E: .doc
git revert --no-edit 5238a9f            # D: rhwp
git revert --no-edit ada6bed            # C: xls·글꼴 맞춤 (E·D가 fonts.rs를 건드림 → 충돌 시 손으로)
git revert --no-edit 9572f9a c3d8ffb    # B: 테마·아이콘
```

의존 관계:
- F → G → H는 차례로 쌓였다. F를 되돌리려면 H, G를 먼저 되돌린다.
- E, G는 C에서 만든 `fonts.rs`에 분기를 더했다. C를 되돌리려면 E와 G의 fonts.rs 부분부터 정리한다.
- D의 `rust/vendor/rhwp/`는 33MB라서, 되돌릴 때 폴더째 빠진다.
