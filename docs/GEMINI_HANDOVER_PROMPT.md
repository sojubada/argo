# 제미나이에게 보낼 말

아래를 붙여넣고, 첨부로 **`HANDOVER.md`, `ROADMAP.md`, `GEMINI_P1_SAFETY.md`** 세 개를 주십시오.
2·3단계 지시서는 1단계가 끝난 뒤에 주시면 됩니다.

---

Apple TV(tvOS 16, SwiftUI + Objective-C, TrollStore 설치)용 파일 탐색기 **Argo**를 함께 만들고 있습니다. 소스 약 14,500줄이 이미 돌아가고 있고, 빌드는 GitHub Actions에서 합니다. 올려 주신 코드는 제가 받아 검수한 뒤 저장소에 반영합니다.

**먼저 `HANDOVER.md` 를 끝까지 읽어 주십시오.** 특히 2장입니다. 그동안 겪은 실패가 전부 적혀 있고, 같은 실수를 되풀이하지 않는 것이 그 문서의 목적입니다. 요점만 추리면

- **애플 문서를 믿지 마십시오.** PDFKit은 "tvOS 11+"로 문서화돼 있지만 SDK에 없습니다. 이걸 믿고 설계한 단계 하나를 통째로 버렸습니다. SDK에 직접 물어보는 워크플로를 만들어 뒀습니다
- **기기에는 WebKit이 있습니다.** SDK에는 없지만 `dlopen` 으로 열면 `WKWebView` 가 완전히 동작합니다. 그래서 문서 뷰어가 JS 렌더러로 돌아갑니다. 헤더가 없으니 **모든 WebKit 호출은 런타임 경유**입니다
- **tvOS에서 입력은 포커스를 가진 뷰에 먼저 갑니다.** 뷰컨트롤러에서 받으려다 방향키가 전부 포커스 이동에 먹혀 아무것도 안 된 적이 있습니다
- **`showSubView` 배열(현재 39)을 건드렸다면 반드시 알려 주십시오.** 안 맞으면 앱이 켜지자마자 죽습니다

이번은 **1단계, 안전장치**입니다. `GEMINI_P1_SAFETY.md` 가 지시서입니다.

Argo는 root 권한으로 돌아서 `/System` 안의 파일도 지웁니다. **그것을 막는 장치가 지금 하나도 없습니다.** 리모컨으로 훑다가 실수하면 애플TV가 부팅을 못 하게 될 수 있고, 복구는 DFU뿐이라 TrollStore까지 날아갑니다. 다음 단계들이 파일을 더 많이·빠르게 다루게 만드는 작업이라, 이것을 먼저 해야 합니다.

범위는 **1단계까지만** 입니다. 두 칸 탐색기와 키보드, 문서 뷰어는 다음에 하겠습니다.

결과는 `HANDOVER.md` 4장의 형식으로 주시고, **확신이 안 서는 부분은 짐작으로 메우지 말고 그대로 적어 주십시오.** 실제 SDK로 확인해서 알려 드리겠습니다.
