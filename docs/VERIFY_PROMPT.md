# 제미나이에게 주는 글 (그대로 붙여넣으십시오)

---

Argo 는 Apple TV(tvOS 16.6 / TrollStore, 탈옥 아님)용 파일 탐색기입니다.
`WhitetailAni/Spartan` 을 포크해 WebDAV·안전장치·두 칸 탐색기·문서 뷰어·
AirDrop 을 더했습니다.

지난 며칠 동안 클로드가 작성한 코드를 **검증**해 주십시오.
첨부한 다섯 문서 중 `VERIFY_INDEX.md` 부터 읽어 주십시오.

## 부탁의 성격

코드 품질 평가가 아니라 **"실제 기기에서 되는가"** 를 봐 주십시오.

빌드는 전부 통과했습니다. 그런데 빌드 통과는 화면에 무엇이 나오는지,
리모컨이 먹는지, 파일이 지워지는지에 대해 아무것도 말해 주지 않습니다.
실제로 지난 며칠간 **빌드가 통과한 코드가 실기기에서 다섯 번 틀렸습니다** —
실행 즉시 종료, 화면 밀림, 파일명 안 보임, 폴더 진입 불가, 삭제 불가.

## 가장 급한 것

**PDF 가 흰 화면으로 나옵니다.** 쪽 수는 읽히는데 아무것도 그려지지 않습니다.
클로드가 렌더링 경로를 바꿨지만 **원인을 모르는 상태에서 바꾼 것**입니다.
`VERIFY_B_READERS.md` 의 Q1 을 먼저 봐 주십시오. 바꾸기 전 코드와 후 코드를
나란히 실어 두었습니다.

## 그 다음

   송·수신은 검증됐지만 **Argo 안에서는 한 번도 안 돌려 봤습니다.**
   특히 수신 광고를 1픽셀 자식 뷰로 붙이는 방식은 클로드가 만든 것으로
   **근거가 없습니다.**
2. **포커스 모델** (`VERIFY_B_READERS.md` Q2) — 같은 수정을 세 뷰어에
   했습니다. 한 곳이 틀리면 세 곳이 틀립니다.
3. **경로 권한** (`VERIFY_C_SAFETY.md` Q1) — 한 번 크게 틀렸던 곳입니다.
   경계표에서 틀린 줄을 찾아 주십시오.
4. **계산 속성 수법** (`VERIFY_D_BROWSER.md` Q1) — 전에 전면 리팩토링을
   지시하셨고 클로드가 반대했는데, **그 반대의 근거가 절반만 맞았습니다.**
   다시 판단해 주십시오.

## 돌려주실 형식

고칠 코드보다 **어디가 왜 틀렸는지**를 주시면 좋겠습니다.
빌드가 한 번에 2~10분 걸려서 추측으로 고치면 왕복만 쌓입니다.

```
[심각도 상/중/하] 파일:줄 — 증상 → 원인 → 근거
```

**근거를 함께 주십시오.** "이러면 안 됩니다" 보다
"애플 문서의 X 는 Y 라고 적혀 있고 이 코드는 Z 를 가정합니다" 가
훨씬 쓸모 있습니다. 근거 없는 단정으로 틀린 적이 양쪽에 여러 번 있습니다.

## 참고

- 코드는 디스크에서 그대로 뽑았습니다 — 문서의 코드 = 빌드되는 코드
- 저장소: `sojubada/argo`, 커밋은 각 문서 머리에 적혀 있습니다
- 루트 헬퍼(`/bin/RootHelper`)는 **실제로 돈 적이 없습니다.**
  모든 쓰기는 `FileManager` 로 갑니다 — 검토도 거기에 집중해 주십시오
