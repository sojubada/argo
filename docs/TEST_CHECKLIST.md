# Argo 기능 시험 항목

Apple TV에 설치한 뒤 확인할 항목입니다.
릴리즈를 만들 때마다 이 문서를 열어 해당 구역만 훑으면 됩니다.

**설치 전 확인** — 설정 > 일반 > 정보 또는 TrollStore에서 빌드 번호를 보고,
방금 올린 빌드가 맞는지 먼저 확인하십시오. 버전은 항상 `1.0`이고,
**빌드 번호**(CFBundleVersion)가 올라갑니다.

판정: ○ 정상 / △ 되지만 어색 / ✗ 안 됨 / − 해당 없음

## A. 기본 (설치 직후 1회)

| # | 항목 | 판정 |
|---|---|---|
| A1 | 홈 화면에 Argo 아이콘이 보이고 실행된다 | |
| A2 | 포커스하면 아이콘이 입체적으로 움직인다 (배·물결·하늘이 각각 다르게) | |
| A3 | 포커스 상태에서 상단에 밤바다 배경이 뜬다 | |
| A4 | 기존 Spartan과 별개 앱으로 공존한다 | |
| A5 | 파일 목록이 뜨고 폴더를 드나들 수 있다 | |

## B. 휴지통

| # | 항목 | 판정 |
|---|---|---|
| B1 | 상단 툴바 휴지통 아이콘(설정 톱니 왼쪽)으로 들어간다 | |

| B6 | 원본 폴더를 지운 뒤 복원하면 폴더가 다시 만들어진다 | |
| B7 | 폴더를 통째로 버렸다 복원해도 내용이 온전하다 | |
| B8 | 영구 삭제에 확인 단계가 있다 | |
| B9 | 휴지통 비우기에 확인 단계가 있다 | |

| B12 | 메뉴 버튼: 상세 → 목록 → 선택해제 → 닫기 순으로 빠져나온다 | |
| B13 | 파일 수십 개를 한 번에 버릴 때 멈추지 않는다 | |

## C. 즐겨찾기

**C2·C3이 핵심입니다.** 저장이 실제로 되는지 보는 항목입니다.

| # | 항목 | 판정 |
|---|---|---|
| C1 | 기존 즐겨찾기 항목이 그대로 보인다 (마이그레이션) | |
| C2 | "Add Current Folder" 로 추가한 뒤 **앱을 완전히 종료했다 다시 켜도 남아 있다** | |
| C3 | 항목을 지우고 **재시작해도 되살아나지 않는다** | |
| C4 | 평소(편집 모드 아닐 때) 항목을 고르면 바로 그 폴더로 이동한다 | |
| C5 | Edit → 항목 선택 → 이름 변경이 된다 | |
| C6 | 위로/아래로 이동으로 순서가 바뀌고, 재시작 후에도 그 순서다 | |
| C7 | 삭제가 된다 | |
| C8 | 상세 추가 화면에서 아이콘을 고를 수 있고, 목록에 그 아이콘이 나온다 | |
| C9 | 이미 등록된 폴더에서는 "Already Added" 로 비활성된다 | |
| C10 | 메뉴 버튼: 편집패널 → 목록 → 닫기 순으로 빠져나온다 | |

## D. WebDAV

| # | 항목 | 판정 |
|---|---|---|
| D1 | 저장된 연결이 그대로 있다 | |
| D2 | 연결 줄을 고르면 바로 탐색 화면이 열린다 (설정으로 가지 않는다) | |
| D3 | "Edit connections" 를 켜면 아이콘이 톱니로 바뀌고, 고르면 설정이 열린다 | |
| D4 | 평문 HTTP(DDNS 주소)로 접속된다 | |
| D5 | 폴더 목록이 제대로 나온다 | |
| D6 | 메뉴 버튼으로 상위 폴더 → … → 연결목록 → 닫기 순으로 올라온다 | |
| D7 | 선택 모드로 여러 파일을 골라 로컬로 복사된다 (진행률 표시) | |
| D8 | 폴더 버튼으로 복사된 로컬 폴더로 바로 이동한다 | |
| D9 | IPA 파일을 골라 TrollStore로 설치된다 | |
| D10 | 큰 파일 다운로드 중 진행률이 올라가고, 끝나면 경로가 표시된다 | |

## E. PDF 뷰어 — 기본 (3단계)

**E1·E2가 핵심입니다.** PDFView 없이 직접 그리는 방식이라 렌더링 정확성이 전부입니다.

| # | 항목 | 판정 |
|---|---|---|
| E1 | PDF를 열면 페이지가 **똑바로** 보인다 (뒤집힘·잘림 없음) | |
| E2 | **가로 페이지**가 섞인 문서에서 회전이 맞다 | |
| E3 | 파일 목록에서 PDF 아이콘이 문서 모양으로 나온다 | |
| E4 | 좌우 스와이프로 페이지가 넘어가고 버벅이지 않는다 | |
| E5 | 위 스와이프 → 상단 툴바, 아래 스와이프 → 페이지 점프 바 | |
| E6 | 툴바가 몇 초 뒤 자동으로 사라진다 | |
| E7 | 보기 모드: 한 쪽 / 연속 스크롤 / 두 쪽(책) 전환이 된다 | |
| E8 | **연속 스크롤**로 긴 문서를 쭉 넘겨도 멈추거나 느려지지 않는다 | |
| E9 | 테마 야간: 글자 흰색, 배경 검정 | |
| E10 | 테마 세피아, 밝기 조절이 반영된다 | |
| E11 | 닫았다 다시 열면 **읽던 쪽**으로 돌아오고 안내가 2초간 뜬다 | |
| E12 | 북마크 토글 후 목록에서 그 쪽으로 점프된다 | |
| E13 | 목차가 있는 PDF에서 목차 항목으로 점프된다 | |
| E14 | 목차가 없으면 "no table of contents" 안내가 뜬다 | |
| E15 | 썸네일 격자가 뜨고 골라서 점프된다 | |
| E16 | 확대 모드: 클릭으로 배율 순환, 방향키로 이동 | |
| E17 | 암호 걸린 PDF에서 비밀번호를 넣으면 열린다 | |
| E18 | 깨진 파일을 열면 크래시 없이 안내 후 닫힌다 | |
| E19 | 메뉴 버튼: 시트 → 툴바 → 확대모드 → 닫기 순으로 빠져나온다 | |
| E20 | 수백 MB짜리 PDF가 있는 폴더를 열 때 목록이 느려지지 않는다 | |

## F. PDF 형광펜 · 검색 (4단계)

| # | 항목 | 판정 |
|---|---|---|
| F1 | 형광펜 모드에 들어가면 선택 상자가 나타난다 | |
| F2 | 방향키로 상자가 움직인다 | |
| F3 | 재생/일시정지로 이동 ↔ 크기조절이 전환되고, 현재 단계가 화면에 표시된다 | |
| F4 | 선택 버튼으로 하이라이트가 칠해진다 | |
| F5 | 색 4가지를 고를 수 있고, 마지막 색이 다음에도 기억된다 | |
| F6 | **페이지를 넘겼다 돌아와도 하이라이트가 그 자리에 있다** | |
| F7 | **확대했다 줄여도 하이라이트가 글자 위 제자리에 있다** | |
| F8 | **앱을 껐다 켜도 하이라이트가 남아 있다** | |
| F9 | 지우개로 겹친 하이라이트가 지워진다 | |
| F10 | 야간 테마에서 하이라이트 색이 어색하지 않다 | |
| F11 | 하이라이트 탭에 쪽 번호 순으로 목록이 나오고 점프된다 | |
| F12 | "Save annotated copy" 로 `원래이름_annotated.pdf` 가 생긴다 | |
| F13 | **그 사본을 열면 하이라이트가 찍혀 있다** | |
| F14 | **원본 PDF는 그대로다** (크기·수정시각 변동 없음) | |
| F15 | 검색어를 넣으면 진행률이 뜨고 쪽 목록이 나온다 | |
| F16 | 결과를 고르면 그 쪽으로 점프된다 | |
| F17 | 최근 검색어 5개가 버튼으로 재사용된다 | |
| F18 | 스캔본 PDF에서는 "No readable text" 안내가 뜬다 (빈 결과가 아니라) | |
| F19 | 검색 중 메뉴 버튼으로 취소된다 | |
| F20 | 형광펜 모드에서 메뉴 버튼으로 빠져나온다 | |

## 시험 중 문제가 나오면

알려주실 내용:

1. **항목 번호** (예: F7)
2. 화면에 뜬 **메시지 그대로**
3. 어떤 파일에서 그랬는지 (크기·종류 — 예: 300MB 스캔본 PDF)
4. 가능하면 **사진**

재현 조건이 명확할수록 빨리 잡힙니다.
"가끔 느려진다" 보다 "300쪽 PDF를 연속 스크롤로 50쪽쯤 내리면 멈춘다" 가
훨씬 유용합니다.
