# Argo 기능 시험 항목

Apple TV에 설치한 뒤 확인할 항목입니다.
릴리즈를 만들 때마다 이 문서를 열어 해당 구역만 훑으면 됩니다.

**설치 전 확인** — 설정 > 일반 > 정보 또는 TrollStore에서 빌드 번호를 보고,
방금 올린 빌드가 맞는지 먼저 확인하십시오. 버전은 항상 `1.0`이고,
**빌드 번호**(CFBundleVersion)가 올라갑니다.

판정: ○ 정상 / △ 되지만 어색 / ✗ 안 됨 / − 해당 없음

## B. 휴지통 · 삭제 권한

**B0 계열이 이번 수정의 핵심입니다.** 임시 경로를 샌드박스 안(`NSTemporaryDirectory()`)으로 옮기고, `FileManager` 먼저 → 실패하면 루트 헬퍼로 넘기는 2단 구조로 바꿨습니다. 어디서 되고 어디서 안 되는지가 중요하니 **경로별로** 봐주세요.

| # | 항목 | 판정 |
|---|---|---|
| B0a | **앱 샌드박스 안** 파일 삭제가 된다 | |
| B0b | `/var/mobile/Media/` 아래 파일 삭제가 된다 | |
| B0c | `/var/mobile/` 바깥(예: `/var/containers`) 파일 삭제가 된다 | |
| B0d | **폴더**(끝에 슬래시 붙는 경로) 삭제가 된다 ← 이전에 실패하던 지점 | |
| B0e | 안 되는 경우 **오류 메시지가 뜬다** (조용히 실패하지 않는다) | |
| B1 | 상단 툴바 휴지통 아이콘(설정 톱니 왼쪽)으로 들어간다 | |
| B2 | 파일을 버리면 휴지통 목록에 뜬다 (원본 경로·시각·크기 표시) | |
| B3 | 복원하면 원래 폴더로 돌아간다 | |
| B4 | 같은 이름 파일 둘을 버려도 둘 다 남는다 | |
| B5 | 같은 자리에 둘 다 복원하면 두 번째가 `이름 (1).확장자` 가 된다 | |
| B6 | 원본 폴더를 지운 뒤 복원하면 폴더가 다시 만들어진다 | |
| B7 | 폴더를 통째로 버렸다 복원해도 내용이 온전하다 | |
| B8 | 영구 삭제에 확인 단계가 있다 | |
| B9 | 휴지통 비우기에 확인 단계가 있다 | |
| B10 | 여러 개 선택해 한 번에 복원·삭제된다 | |
| B11 | 구버전에서 버린 파일은 "Unknown original location" 으로 뜨고 복원 버튼이 꺼져 있다 | |
| B12 | 메뉴 버튼: 상세 → 목록 → 선택해제 → 닫기 순으로 빠져나온다 | |
| B13 | 파일 수십 개를 한 번에 버릴 때 멈추지 않는다 | |

**C2·C3이 핵심입니다.** 저장이 실제로 되는지 보는 항목입니다.

| # | 항목 | 판정 |
|---|---|---|

| C6 | 위로/아래로 이동으로 순서가 바뀌고, 재시작 후에도 그 순서다 | |
| C7 | 삭제가 된다 | |
| C8 | 상세 추가 화면에서 아이콘을 고를 수 있고, 목록에 그 아이콘이 나온다 | |
| C9 | 이미 등록된 폴더에서는 "Already Added" 로 비활성된다 | |

## E. PDF 뷰어 (경량화판)

**E1·E2가 핵심입니다.** PDFKit이 tvOS에 없어 Core Graphics로 직접 그리는 방식이라, 렌더링 정확성이 전부입니다.

목차·북마크·썸네일·세피아·연속스크롤·확대는 요청대로 **삭제했습니다.** 남은 기능은 읽기 / 야간 / 두 쪽(책) / 쪽넘김 효과뿐입니다.

| # | 항목 | 판정 |
|---|---|---|
| E1 | PDF를 열면 페이지가 **똑바로** 보인다 (뒤집힘·잘림 없음) | |
| E2 | **가로 페이지**가 섞인 문서에서 회전이 맞다 | |
| E3 | 파일 목록에서 PDF 아이콘이 문서 모양으로 나온다 | |
| E4 | 방향키 좌/우로 쪽이 넘어가고 버벅이지 않는다 | |
| E5 | 쪽이 넘어갈 때 **책장 넘기는 효과**가 보인다 | |
| E6 | 기본이 **두 쪽(책)** 보기로 열린다 | |
| E7 | 툴바의 `1 Page` / `2 Pages (Book)` 버튼으로 전환된다 | |
| E8 | 두 쪽 보기에서 **왼쪽이 앞 쪽, 오른쪽이 뒤 쪽** 순서가 맞다 | |
| E9 | 마지막이 홀수 쪽이면 오른쪽이 비어도 깨지지 않는다 | |
| E10 | **재생/일시정지 버튼**으로 야간 모드가 바로 바뀐다 | |
| E11 | 야간 모드에서 글자 흰색, 배경 검정 | |
| E12 | 툴바 `Day` / `Night` 버튼도 같이 동작한다 | |
| E13 | 가운데(선택) 또는 위/아래 방향키로 툴바가 올라온다 | |
| E14 | 툴바가 몇 초 뒤 자동으로 사라진다 | |
| E15 | `First` / `Prev` / `Next` / `Last` 가 동작하고, 양 끝에서 비활성된다 | |
| E16 | 닫았다 다시 열면 **읽던 쪽**으로 돌아오고 안내가 잠깐 뜬다 | |
| E17 | 보기 모드와 야간 설정이 **다음에 열 때도 기억된다** | |
| E18 | 암호 걸린 PDF에서 비밀번호를 넣으면 열린다 | |
| E19 | 깨진 파일을 열면 크래시 없이 안내 후 닫힌다 | |
| E20 | 메뉴 버튼: 툴바 → 닫기 순으로 빠져나온다 | |
| E21 | 수백 쪽 문서를 빠르게 넘겨도 멈추거나 쌓이지 않는다 | |

## F. 문서 뷰어 — 워드 · 엑셀 · PPT · 한글

ZIP 기반(`.docx` `.xlsx` `.pptx` `.hwpx`)은 내부 XML을 읽고, 구형 바이너리(`.doc` `.xls` `.ppt` `.hwp`)는 텍스트 스트림만 긁어냅니다. **서식·표·그림은 안 나옵니다. 글자만 읽는 기능입니다.**

| # | 항목 | 판정 |
|---|---|---|
| F1 | `.docx` 를 열면 본문 글자가 순서대로 나온다 | |
| F2 | `.xlsx` 를 열면 **시트 이름이 상단 탭**으로 나오고 전환된다 | |
| F3 | `.xlsx` 셀 값(문자·숫자)이 행 단위로 읽힌다 | |
| F4 | `.pptx` 를 열면 **슬라이드별 탭**이 나오고 글상자 내용이 읽힌다 | |
| F5 | `.hwpx` 한글 문서의 본문이 읽힌다 | |
| F6 | `.hwp` (구형 바이너리) 에서 글자가 어느 정도 읽힌다 — 깨져도 크래시는 없어야 함 | |
| F7 | `.doc` / `.xls` / `.ppt` 구형 파일도 열리고 안내든 글자든 나온다 | |
| F8 | 읽을 글자가 없으면 "No readable text found in this section." 안내가 뜬다 | |
| F9 | 파일 목록에서 이 파일들이 **압축 파일(지퍼) 아이콘이 아니라 문서 아이콘**으로 나온다 ← 중요 | |
| F10 | `Day` / `Night` 전환이 된다 | |
| F11 | 방향키로 줄 목록을 스크롤할 수 있다 | |
| F12 | `Close` 또는 메뉴 버튼으로 닫힌다 | |
| F13 | 대문자 확장자(`.DOCX`, `.PDF`)도 똑같이 인식된다 | |
| F14 | 10MB 이상 문서를 열 때 멈추지 않고 안내 뒤 내용이 나온다 | |

## 시험 중 문제가 나오면

알려주실 내용:

1. **항목 번호** (예: F7)
2. 화면에 뜬 **메시지 그대로**
3. 어떤 파일에서 그랬는지 (크기·종류 — 예: 300MB 스캔본 PDF)
4. 가능하면 **사진**

재현 조건이 명확할수록 빨리 잡힙니다.
"가끔 느려진다" 보다 "300쪽 PDF를 연속 스크롤로 50쪽쯤 내리면 멈춘다" 가
훨씬 유용합니다.
