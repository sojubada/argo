# 키보드 단축키

애플TV에 블루투스 키보드를 붙이면 (설정 → 리모컨 및 기기 → 블루투스) 파일 관리가
리모컨과는 다른 물건이 됩니다. 아래는 넣을 단축키 전체 목록입니다.

맥 핀더 관례를 따릅니다. 애플 키보드를 쓰시니 손이 이미 그렇게 기억하고 있습니다.

---

| `Page Up` `Page Dn` | 한 화면씩 | |
| `Home` `End` | 맨 위 / 맨 아래 | |

| `⌘ [` `⌘ ]` | 이전 / 다음 폴더 | 방문 기록 |

`ㅂ` 한 번 치는 것은 비교가 안 됩니다.

|---|---|

| `⌘ R` 또는 `F5` | 새로 고침 |

## 정해야 할 것 — `⌘ Z`

`⌘ Z` 로 압축하자고 하셨습니다. Z = Zip 이라 외우기 좋습니다.

다만 `⌘ Z` 는 **모든 프로그램에서 되돌리기**입니다. 손이 그렇게 기억하고 있어서,
파일을 옮기다 실수하면 반사적으로 `⌘ Z` 를 누르실 겁니다. 그때 압축이 걸리면
곤란합니다.

**권하는 쪽:** `⌘ Z` 는 되돌리기로 두고 압축은 `⌘ ⇧ Z` 로.
지금 Argo에는 되돌리기가 없지만, 삭제·이동이 잦은 프로그램에 되돌리기가 없는 것이
오히려 문제입니다. 휴지통이 이미 있으니 복원 경로는 절반쯤 깔려 있습니다.

그래도 `⌘ Z` = 압축이 좋으시면 그렇게 하겠습니다. 위 표만 고치면 됩니다.

## 정해야 할 것 — `Return`

핀더에서 `Return` 은 **이름 바꾸기**이고 열기는 `⌘ O` 입니다.
TV에서는 `Return` = 열기가 자연스러워 그렇게 잡았고, 이름 바꾸기를 `⌘ R` 로 옮겼습니다.
핀더 습관대로 가고 싶으시면 바꾸겠습니다.

## 구현 메모

- **발견 가능성이 문제입니다.** tvOS에는 메뉴 막대가 없어 단축키를 알 길이 없습니다.
  `⌘ /` 로 뜨는 도움말 화면이 반드시 있어야 합니다. 처음 키보드를 붙였을 때
  한 번 안내하는 것도 좋습니다
- **글자 입력 점프와 텍스트 입력이 충돌합니다.** 경로·검색 칸에 포커스가 있을 때는
  단축키가 먹으면 안 됩니다
- 시스템이 쓰는 조합은 피합니다 — `⌘ Space`, `⌘ Tab`
- 키보드를 빼도 리모컨만으로 **모든 기능이 되어야 합니다.** 단축키는 지름길이지
  유일한 길이 아닙니다
