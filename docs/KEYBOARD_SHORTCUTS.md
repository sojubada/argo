# 키보드 단축키

> **갱신 2026-10-22** — 복사·이동 맵핑을 바꿨습니다. 아래가 지금 코드와 같습니다.
> 정의는 `ArgoCommand.binding(for:)` 한 곳에 있고 `⌘/` 도움말이 같은 함수를 읽으므로
> 표시와 실제가 어긋날 수 없습니다.

## 복사 · 이동  ★바뀜★

| 키 | 동작 |
| --- | --- |
| `⌘C` | 복사 (클립보드에 담기) |
| `⌘X` | 잘라내기 |
| `⌘V` | **이 폴더에 붙여넣기** |
| `⌥⌘C` | 반대 칸으로 바로 복사 (두 칸일 때) |
| `⌥⌘X` | 반대 칸으로 바로 이동 (두 칸일 때) |

**왜 바꿨나.** 전에는 `⌘C` 가 '반대 칸으로 바로 복사'였습니다. 두 칸을 켜지 않으면
**복사할 길이 아예 없었고**, 목적지를 고를 수도 없었습니다. 표준 자리를 표준 동작에
돌려주고, 두 칸 지름길은 `⌥` 를 붙였습니다.

클립보드에 무언가 담기면 **툴바에 붙여넣기 버튼이 나타납니다** — 키보드 없이
리모컨만으로도 되고, 버튼이 보이는 것 자체가 '담겨 있다'는 표시입니다.

## 이동

| 키 | 동작 |
| --- | --- |
| `⌘↑` | 한 칸 위로 |
| `⌘[` / `⌘]` | 뒤로 / 앞으로 |
| `⌘⇧H` | 미디어 폴더로 |
| `⌘⇧/` | 최상위로 |
| `⌘R` | 새로 읽기 |
| 글자 입력 | 그 글자로 시작하는 첫 항목으로 점프 |

## 두 칸

| 키 | 동작 |
| --- | --- |
| `⌘2` | 두 칸 켜고 끄기 |
| `⌥Tab` | 반대 칸으로 |
| `⌘=` | 반대 칸을 이 폴더로 맞추기 |

## 파일

| 키 | 동작 |
| --- | --- |
| `⌘⇧N` / `⌘N` | 새 폴더 / 새 파일 |
| `⌘Return` | 이름 바꾸기 |
| `⌘I` | 정보 |
| `⌫` | 삭제 (미리보기를 거칩니다) |
| `⌘⇧Z` | 압축 |
| `⌘E` | 압축 풀기 |
| `⌘Z` | 되돌리기 (이동·이름 바꾸기만) |

## 고르기 · 보기

| 키 | 동작 |
| --- | --- |
| `⌘M` | 여러 개 고르기 |
| `⌘A` | 전부 고르기 |
| `⌘⇧.` | 숨긴 항목 |
| `⌥⌘1~4` | 이름 · 크기 · 날짜 · 종류 순 |
| `⌘T` | 정렬 뒤집기 |
| `⌘F` | 찾기 |
| `⌘/` | **단축키 도움말** |

---

## 지키는 규칙

- **키보드를 빼도 리모컨만으로 모든 기능이 됩니다.** 단축키는 지름길이지 유일한 길이 아닙니다
- **글자를 받는 칸에 포커스가 있으면 단축키가 안 먹습니다** — 경로 칸과 시트 5개에 연결돼 있습니다
- `⌘Space` · `⌘Tab` 은 시스템이 씁니다. 맨 `Tab` 도 포커스 엔진이 쓰므로 피했습니다
- tvOS 에는 메뉴 막대가 없어 **`⌘/` 도움말이 단축키를 알 수 있는 유일한 길**입니다
