Apple TV용 파일 탐색기 **Argo**(tvOS 16, SwiftUI, TrollStore 설치)를 함께 만들고 있습니다.
빌드는 GitHub Actions에서 돌고, 올려 주신 코드는 제가 받아 검수한 뒤 저장소에 반영합니다.

이번 단계는 **두 가지**입니다. 순서대로 해 주십시오.

**첫째, 진단 화면(Lab)을 만듭니다.**
기능마다 점검 항목을 버튼 하나로 돌려 보고, 통과·실패를 화면 로그로 남기는 화면입니다.
앞으로 모든 기능을 이 화면으로 한 항목씩 확인하면서 진행할 것이라, 이번 단계에서 가장 중요합니다.

**둘째, 워드 문서 읽기를 제대로 만듭니다.**
지금 문서 뷰어는 글자만 나열합니다. 쪽도 여백도 없어 문서로 읽히지 않습니다.
원본 서식 그대로 변환하는 것은 tvOS에 레이아웃 엔진이 없어 불가능하니,
**추출한 내용을 CoreText로 조판해 진짜 PDF로 만들고, 이미 잘 동작하는 PDF 뷰어에 넘기는** 방식으로 갑니다.
닫을 때 임시 PDF는 지웁니다.

함께 고칠 버그가 하나 있습니다. 원인까지 확인해 두었습니다.
독일어 워드 문서에서 한 문단이 단어마다 줄바꿈되는데, `extractParagraphs` 가 태그를 접두어로만 비교해
`<w:p` 가 `<w:proofErr` 에도 걸리기 때문입니다. 자세한 것은 지침서 3장에 있습니다.

**첨부한 `GEMINI_STAGE5_SPEC.md` 를 먼저 끝까지 읽어 주십시오.** 특히 이 셋은 꼭 지켜 주십시오.

- **PDFKit과 WebKit은 tvOS에 없습니다.** 애플 문서에는 있다고 나오지만 SDK에 실물이 없어 한 번 크게 돌아간 적이 있습니다. 쓸 수 있는 API 목록을 지침서 1장에 적어 두었고, `DocPipelineProbe.swift` 에 실제로 컴파일되는 호출 예가 들어 있습니다
- **tvOS는 한 행이 통째로 포커스 단위**라, 한 행에 버튼이 둘이면 뒤쪽 것만 눌립니다. 한 화면에 `.sheet` 도 하나만 됩니다
- **`showSubView` 배열 크기를 건드렸다면 반드시 알려 주십시오.** 안 맞으면 앱이 켜지자마자 죽습니다

범위는 **A(워드)까지만** 입니다. 표·발표자료·한글은 다음 단계에서 하겠으니, 진단 화면 목록에는 올리되 내용은 비워 두십시오.

결과는 지침서 6장의 형식으로 주시고, **확신이 안 서는 부분은 짐작으로 메우지 말고 그대로 적어 주십시오.**
제가 실제 SDK로 확인해서 알려 드리겠습니다.
