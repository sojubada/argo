## 1단계 — 첫 메시지 (사양서 첨부와 함께)

```
당신은 tvOS(Apple TV) 앱 개발자입니다. SwiftUI와 PDFKit에 능숙합니다.

제가 운영하는 오픈소스 프로젝트 "Argo"의 기능을 확장하려 합니다.
Argo는 Apple TV용 파일 브라우저입니다. WebDAV 접속과 TrollStore를 통한
IPA 설치 기능을 갖추고 있고, WhitetailAni의 Spartan(MIT)을 포크한 것입니다.

첨부한 GEMINI_TASK_SPEC.md 가 작업 사양서입니다. 전부 읽고 그대로 따라 주십시오.

특히 다음 다섯 가지를 반드시 지켜 주십시오. 어기면 결과물을 쓸 수 없습니다.

1. 새 외부 라이브러리를 추가하지 마십시오. Apple 기본 프레임워크만 쓰십시오.
2. tvOS 16.0에 존재하는 API만 쓰십시오. 확실하지 않으면 쓰지 말고
   "확신이 없는 부분"에 적어 주십시오.
3. 존재하지 않는 메서드나 시그니처를 추측으로 지어내지 마십시오.
   모르면 모른다고 적는 쪽이 훨씬 낫습니다.
4. Xcode 프로젝트 파일(project.pbxproj)은 직접 수정하지 마십시오.
   새로 만든 파일 목록만 적어 주시면 제가 등록합니다.
5. 코드는 생략 없이 파일 전체를 주십시오. "…이하 동일" 같은 생략은 안 됩니다.

저는 로컬에서 컴파일할 수 없는 환경입니다. 빌드는 GitHub Actions에서
Xcode 15.4로 돌아갑니다. 따라서 화려하지만 불확실한 코드보다
단순하고 확실하게 동작하는 코드를 주십시오.

작업은 사양서 4.3절의 순서대로 4단계로 나눠 진행합니다.
지금은 **1단계(휴지통)만** 작성해 주십시오.
제가 검수하고 빌드가 통과하면 "2단계 진행"이라고 말하겠습니다.

1단계 범위:
- Spartan/Trash/TrashManager.swift (신규)
- Spartan/Trash/TrashView.swift (신규)
- Spartan/ContentView.swift 수정 (치환 지시 형식으로)
- showSubView 배열 크기 36 → 38 확장

사양서 4.1절의 제출 형식과 4.2절의 자가 점검 목록을 반드시 지켜 주십시오.
```

## 검수자(저)가 할 일

Gemini 결과물을 저에게 주시면 제가 이렇게 처리합니다.

1. **정적 검수** — 존재하지 않는 API, 시그니처 오류, tvOS 16 미지원 API 확인
2. **사양 위반 확인** — 행당 버튼 하나 규칙, 단일 `.sheet`, `showSubView` 크기, 원본 PDF 미수정, root 쓰기 경로
3. **치환 적용** — `ContentView.swift` 치환 지시를 실제로 적용
4. **pbxproj 등록** — 새 `.swift` 파일을 Xcode 프로젝트에 등록
5. **프로젝트 설정 반영** — `TVOS_DEPLOYMENT_TARGET`, `MinimumOSVersion`
6. **커밋 & 푸시** — `sojubada/argo` main 브랜치
7. **CI 감시** — 빌드 실패 시 에러 수집. 단순 오류는 제가 바로 고치고,
   설계가 얽힌 것이면 Gemini에 되돌릴 로그를 정리해 드립니다
8. **릴리스 확인** — IPA가 나오면 내려받아 Info.plist / 엔타이틀먼트 / 포함 여부 검증

결과물을 받으시면 **이 대화창에 그대로 붙여넣어** 주십시오.
파일이 길면 단계별로 나눠서 주셔도 됩니다.
