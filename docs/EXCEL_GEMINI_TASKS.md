## 0. 공통 머리말 (매 단계마다 앞에 붙일 것)

```
너는 Argo(애플TV용 파일 탐색기·문서 뷰어)에 엑셀 셀 단위 뷰어를 붙이는 작업을 한다.
저장소는 sojubada/argo. 아래 규칙은 모든 단계에 적용된다.

[환경]
- Rust 코드는 rust/ 아래. 새 크레이트는 rust/argosheet.
- 빌드 대상은 aarch64-apple-tvos, nightly 툴체인에 -Z build-std. 따라서
  의존성은 순수 Rust 만 쓴다. C 바인딩이 있는 크레이트(libxml2, zlib-sys,
  freetype 등)는 쓰지 않는다. zip·xml·소수 연산도 순수 Rust 로 된 것만.
- 이미 쓰는 것: quick-xml, rust_decimal. 새 의존성을 추가하려면 먼저 이름과
  이유를 적어 물어본다.
- Swift 는 tvOS 16.0 최소, UIKit. SwiftUI 는 쓰지 않는다(포커스가 안 잡힌다).

[재사용 — 새로 짜지 말고 옮겨 쓸 것]
rust/vendor/minipdf/src/xlsx.rs 안의 다음 함수는 이미 실제 문서로 검증됐다.
  - read_part_relationships, resolve_part_target : ZIP 안 부품 관계 읽기
  - read_theme_colors, apply_color_tint          : 테마 색과 밝기 보정(tint)
  - excel_column_width_to_points_with_mdw, excel_max_digit_width : 열 너비 환산
  - rasterize_emf, read_legacy_drawing_images    : EMF·레거시 그림
그대로 argosheet 로 옮기고, 고칠 일이 있으면 무엇을 왜 고쳤는지 적는다.

[쓰지 말 것 — 이미 실패한 길]
- CoreXLSX, XMLCoder : 시트 전체를 Codable 로 올려 큰 시트에서 메모리가 터진다.
- NSExpression       : 문법이 조금만 달라도 ObjC 예외가 나고 Swift 에서 못 잡아
                       앱이 그대로 종료된다. 수식은 직접 파서를 만든다.
- NumberFormatter 로 엑셀 서식 흉내 : 반올림 규칙이 달라 2.5 가 2 로 나온다.
- 셀마다 포커스를 받는 UICollectionView : 포커스 후보가 수백 개가 되고 확대
                       효과가 이웃 테두리를 가린다. 타일 + 셀 커서 하나로 간다.
- 정규식으로 수식 문자열의 셀 참조를 치환 : LOG10 이 셀 참조로 바뀐다.
- 남의 바이너리·스크립트를 내려받아 실행하지 않는다.

[코드 규칙]
- 모든 C ABI 진입점은 catch_unwind 로 감싸고 오류는 코드로 돌려준다. 패닉이
  경계를 넘으면 앱이 죽는다.
- 좌표는 엑셀 pt 하나로만 계산한다(EMU·픽셀·문자 단위를 섞지 않는다).
- 주석은 한국어로, "무엇을" 이 아니라 "왜" 를 적는다.
- 시험 벡터는 코드 안 #[test] 로 넣는다. 시험 없는 계산 코드는 받지 않는다.

[합격 판정]
- 정답 파일 golden_values.json (시트 7개, 수식 1,208칸, LibreOffice 로 재계산)
  과 비교한다. 숫자는 상대오차 1e-9, 글은 완전 일치.
- 보기 전용이다. 셀 값을 바꾸는 길(입력·목록 선택·저장)은 만들지 않는다.

[제출물]
- 바뀐 파일 전체 내용(조각 diff 말고).
- 새 시험 목록과 돌린 결과.
- 못 한 것·의심스러운 것을 끝에 솔직히 적는다. 지어내지 않는다.
```

## P0 — 크레이트 뼈대와 시험 틀

```
[목적] argosheet 크레이트를 세우고, 파일을 열어 시트 목록과 셀 원래 값을
출력하는 CLI 까지 만든다. 화면·수식은 아직 없다.

[할 일]
1. rust/argosheet 를 만든다. Cargo.toml 은 rust/argoconv/Cargo.toml 을 본떠
   crate-type = ["staticlib", "rlib"], 순수 Rust 의존성만.
2. ZIP 읽기와 부품 관계 해석을 minipdf/xlsx.rs 에서 옮긴다.
3. quick-xml 스트리밍으로 다음을 읽는다.
   - xl/workbook.xml : 시트 이름·ID·숨김 여부, 정의된 이름(definedName),
     calcPr(fullCalcOnLoad), date1904 여부
   - xl/worksheets/sheetN.xml : 행·열 번호, 셀 주소, 값 종류(t 속성),
     값(<v>), 수식(<f>, t="shared"·"array" 포함), 인라인 문자열(<is>)
   - xl/sharedStrings.xml (있으면)
4. C ABI 를 다음 다섯 개만 먼저 만든다. 모두 catch_unwind.
   as_open(path) -> *mut Book / as_close / as_sheet_count
   as_sheet_info(book, index, *out) / as_last_note(*char)
5. CLI: cargo run --release --example argosheet_dump -- <파일.xlsx>
   시트마다 "이름 · 행수 · 열수 · 셀수 · 수식수" 를 찍고,
   --cells <시트> 를 주면 "주소<TAB>종류<TAB>원래값<TAB>수식" 을 찍는다.
6. CI(.github/workflows)에 리눅스 cargo test 와 tvOS 컴파일 확인을 더한다.

[주의]
- 이 샘플 파일은 수식 1,208칸의 <v> 가 전부 비어 있다(openpyxl 로 만든 파일,
  fullCalcOnLoad=1). 값이 없다고 파싱 실패로 처리하면 안 된다.
- 문자열은 전부 인라인(t="inlineStr")이다. sharedStrings 가 없어도 열려야 한다.
- 행·열은 1부터. 빈 행·빈 칸이 건너뛰어 있어도 자리를 지켜야 한다.

[합격]
- 샘플 파일에서 시트 7개가 나오고, 시트별 수식 수가
  37 / 248 / 186 / 325 / 126 / 145 / 141 (합 1,208) 로 맞는다.
- 수식 1,208칸이 모두 문자열로 읽힌다(분석 실패 0).
- 망가뜨린 파일(앞 100바이트 지움, 중간 1KB 뒤집음 등) 10개에서 패닉 0.
```

## P1 — 모델·서식·수식 엔진 (가장 큰 단계)

이 단계는 셋으로 쪼개 순서대로 준다. 앞 것이 끝나야 다음을 준다.

### P1-a 데이터 모델과 스타일

```
[할 일]
1. 셀 저장: 행 단위 압축(CSR). 셀 하나는 16바이트 고정으로 맞춘다

   자동 필터 범위(autoFilter), 데이터 유효성(dataValidation), 메모(comments).

[합격]
- 샘플 7개 시트에서 열 너비 13~44문자, 제목 행 높이 28·18pt 가 pt 로 나온다.
- 병합 14곳, 틀 고정 1곳(01 시트 E5), 유효성 5곳, 메모 5곳이 모두 잡힌다.
- 메모리: 샘플 파일 전체를 올렸을 때 50MB 이하.

### P1-b 숫자·날짜 서식 엔진

```
[할 일]
서식 코드를 한 번만 토큰으로 쪼개 구문 트리로 만들고(서식 번호별 캐시),
값마다 트리를 실행한다. 문자열 치환·정규식으로 처리하지 않는다.

- 섹션 최대 4개: 1개=전부, 2개=양수·0/음수, 3개=양수/음수/0, 4번째=문자.
  음수 섹션은 절댓값을 쓰고 부호를 붙이지 않는다(서식에 - 나 괄호가 있다).
- 토큰: 0 # ? . , % E+ E- / "글자" \글자 _x *x @ 그리고 날짜·시간
  (yyyy yy m mm mmm mmmm d dd ddd dddd aaa aaaa h hh s ss .0 [h] [m] [s]
   AM/PM 오전/오후).
- 반올림: 값을 유효숫자 15자리로 맞춘 뒤(엑셀 정밀도) 필요한 자리에서
  0에서 먼 쪽으로. rust_decimal 로 십진 연산. f64 로 하면 1.005 가 1.00 이 된다.
- [Red] 같은 색, [$₩-412] 로케일, [DBNum1~4], [>=100] 조건.
- General: 정수는 그대로, 소수는 가용 폭(기본 11글자)에 맞춰 자릿수를 줄인다.

[이 샘플이 쓰는 서식 — 반드시 통과]
  yyyy-mm-dd · yyyy-mm · 0.0% · 0.0000
  $#,##0.00;($#,##0.00);"-"   · $#,##0;($#,##0);"-"
  내장 3(#,##0) · 4(#,##0.00) · 10(0.00%)

[시험 벡터 — 코드 안 #[test] 로]
  (1234.5, "#,##0")        -> "1,235"
  (-1234.5, "$#,##0;($#,##0);\"-\"") -> "($1,235)"
  (0, "$#,##0;($#,##0);\"-\"")       -> "-"
  (0.125, "0.00")          -> "0.13"      (0에서 먼 쪽, 짝수 반올림 아님)
  (2.5, "0")               -> "3"
  (1.005, "0.00")          -> "1.01"
  (0.0825, "0.0%")         -> "8.3%"
  (45292, "yyyy-mm-dd")    -> "2023-12-31"
  (45292, "yyyy-mm")       -> "2023-12"
  (1, "yyyy-mm-dd")        -> "1900-01-01"
  (60, "yyyy-mm-dd")       -> "1900-02-29"   (엑셀의 1900 윤년 버그를 그대로)
  (61, "yyyy-mm-dd")       -> "1900-03-01"
```

### P1-c 수식 엔진 (함수 64개)

```
[할 일]
1. 파서: 토큰 → 구문 트리. 연산자 우선순위(: 범위, 공백 교집합, , 합집합,
   단항 -, %, ^, * /, + -, &, 비교). 참조는 A1·$A$1·A:A·1:1·'시트 이름'!A1·
   정의된 이름. 문자열은 "" 로 감싸고 "" 는 따옴표 하나.
2. 값 모델: 숫자 / 문자 / 논리 / 오류(#DIV/0! #VALUE! #REF! #NAME? #NUM! #N/A) /
   빈 칸. 빈 칸은 수식에서 0 이자 "" 이다. 오류는 위로 전파된다.
3. 공유 수식(t="shared"): 주 수식의 상대 참조를 칸 차이만큼 옮겨 쓴다.
   엑셀이 저장한 파일 대부분이 이 꼴이다.
4. 배열 수식(t="array") : 결과 한 칸만 쓰는 꼴까지.
5. 의존 그래프: 셀 → 참조하는 셀. 위상 정렬로 한 번에 계산.
   순환 참조는 #VALUE! 대신 0 으로 두고 경고 목록에 적는다.
6. OFFSET 처럼 참조가 실행 중에 정해지는 함수가 든 칸은 "항상 다시 계산" 으로
   표시한다(이 샘플엔 02 시트 한 곳뿐이다).

[함수 64개 — 묶음별 주의할 점]
 논리·정보 IF AND OR IFERROR ISNUMBER ISTEXT
   - IF 는 고르지 않은 가지를 계산하지 않는다(지연 평가).
 수학 SUM ABS ROUND MAX SUMPRODUCT LARGE RANK
   - ROUND 는 0에서 먼 쪽. SUM 은 글·논리·빈 칸을 무시한다.
   - SUMPRODUCT 는 배열끼리 곱해 더하고, 논리값은 1/0 으로 센다.
 조건 집계 SUMIF SUMIFS COUNTIF COUNTIFS AVERAGEIF SUBTOTAL COUNT COUNTA AVERAGE
   - 조건은 ">=100" 같은 문자열과 와일드카드 * ? 를 받는다.
   - SUBTOTAL 101~111 은 숨은 행을 뺀다.
 조회 INDEX MATCH VLOOKUP CHOOSE OFFSET ADDRESS
   - MATCH 의 세 번째 인수 0(정확)·1(오름차순 근사)·-1(내림차순).
   - VLOOKUP 네 번째 인수를 빼면 근사 일치다.
 문자 LEN TRIM MID RIGHT FIND SUBSTITUTE REPT PROPER TEXT
   - 한글 한 글자는 1이다(바이트가 아니다).
   - FIND 는 대소문자를 가리고 1부터 세며 못 찾으면 #VALUE!.
   - TRIM 은 앞뒤 공백을 지우고 안쪽 연속 공백을 한 칸으로 줄인다.
   - PROPER 는 낱말 첫 글자만 대문자. TEXT 는 P1-b 서식 엔진을 호출한다.
 날짜 DATEDIF NETWORKDAYS EOMONTH EDATE WEEKDAY
   - 1900 날짜 체계(윤년 버그 포함). NETWORKDAYS 는 토·일만 뺀다(휴일 인수 없음).
   - EDATE·EOMONTH 는 월말 보정을 한다(1/31 + 1개월 = 2/28).
 재무 NPV IRR MIRR SLN DB DDB SYD PMT IPMT PPMT
   - NPV 는 첫 값을 1기 말로 할인한다(0기 아님).
   - DB 는 감가율을 소수 셋째 자리로 반올림한다. 이걸 빼면 값이 틀린다.
   - DDB 는 마지막 기에 잔존가 아래로 내려가지 않는다.
   - IRR 은 초기값 0.1 뉴턴법 + 이분법 보강, 1e-7 허용, 실패하면 #NUM!.
   - PMT 계열 부호: 받는 돈 +, 갚는 돈 -.
 통계 FORECAST STDEV.S STDEV.P VAR.S CORREL SLOPE INTERCEPT RSQ MEDIAN
      QUARTILE PERCENTILE
   - STDEV.S 셈법(Rob 지정):
       ① 범위에서 숫자만 고른다(글·논리·빈 칸 제외)
       ② 개수가 2 미만이면 #DIV/0!
       ③ 평균을 구한다
       ④ (값-평균)² 합을 n-1 로 나누고 제곱근
     STDEV.P 는 n 으로 나눈다. VAR.S 는 ④에서 제곱근을 씌우지 않는다.
   - QUARTILE·PERCENTILE 은 포함 방식 선형 보간.
 기타 HYPERLINK — 값은 두 번째 인수(표시 글), 첫 번째는 링크 주소.

[이 샘플의 함정]
- 06 시트의 STDEV.S·STDEV.P·VAR.S 39칸은 파일에 _xlfn. 접두어가 없다.
  이름표에 "STDEV.S" 와 "_xlfn.STDEV.S" 를 모두 등록해 **계산해 준다**
  (#NAME? 로 두지 않는다. Rob 결정).
- 02 시트 유효성 목록의 수식은 앞에 = 가 붙어 있다('01_...'!$A$5:$A$64 앞).
  규격과 다르니 앞의 = 를 벗기고 해석한다.
- 03 시트 A열 원문에는 앞뒤 공백이 있다(xml:space="preserve"). 지우면 TRIM
  결과가 틀린다.
- 동적 배열(XLOOKUP FILTER SORT UNIQUE SEQUENCE)은 이번 범위가 아니다.
  만나면 계산하지 말고 "아직 계산하지 않는 함수" 로 표시한다.

[합격]
- golden_values.json 과 비교해 1,208칸 중 99%(1,196칸) 이상 일치.
- 맞춰 가는 순서는 03 → 05 → 06 → 02 → 04 → 01 → 00. 05(재무)와 03(문자)이
  가장 많이 틀린다.
- 시험은 시트별로 "일치 수 / 전체 수" 를 찍고, 틀린 칸은 주소·기대·실제를
  최대 20개까지 보여 준다.
```

## P1b — 함수 늘리기 (120개 목록의 나머지)

```
[할 일]
- 예전 사양의 120개 목록 가운데 P1 에서 뺀 함수들을 더한다(수학·문자·날짜·

## P3 — 그리는 규칙 맞추기

```
[할 일]
- 격자선: showGridLines 가 켜져 있고 **양쪽 셀 모두 채우기가 없는 변에만**
  (#D9D9D9, 1px).
- 테두리: 한 변은 한 번만 그린다. 양쪽이 다르면 굵기 순위(thick > double >
  medium > thin > hair), 같으면 오른쪽·아래 셀 것. 13종 + 대각선.
- 글 넘침: 줄바꿈·회전·셀에 맞춤이 아니고 정렬이 일반·왼쪽·오른쪽·가운데인
  **문자** 셀만 옆 빈 칸으로 넘친다. 값이 있는 칸을 만나면 그 앞에서 자른다.
  숫자·날짜는 절대 넘치지 않는다 — General 이면 자릿수를 줄이고, 그래도
  넓으면 지수, 그래도 넓으면 # 로 채운다.
- 정렬: 일반(문자 왼쪽·숫자 오른쪽), fill, justify, **distributed(균등 분할)**,
  centerContinuous, 세로 정렬 기본은 bottom, indent, 회전 1~180, 255(세로쓰기),
  shrinkToFit.
- 셀 안쪽 여백은 좌우 1.5pt(2px). 10pt 로 두면 엑셀보다 글이 일찍 잘린다.
- 줄바꿈은 공백에서 끊고, 한 낱말이 칸보다 길면 글자에서 끊는다.
- 줄 끝 문장부호(, . : ; ) ] 》 」 ·)는 칸 밖으로 매단다(파워포인트·한글과 같다).
- 메모 삼각형과 내용, 하이퍼링크(내부 점프·외부는 QR 그림).
- 대체 글꼴로 그릴 때 글자가 칸 밖으로 나가거나 줄 높이를 밀지 않게 자른다.

[합격] 표시 문자열 99.5% 일치, 00·01 시트가 LibreOffice PDF 와 눈으로 같다.
```
